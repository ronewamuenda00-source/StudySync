# StudySync

## 1. Project Overview

StudySync is a student-focused website prototype designed to help university students organise their academic activities in one place. It combines study group collaboration, study scheduling, task tracking, and basic profile management in a simple, consistent interface.

## 2. Main Features

- **Dashboard:** Provides an overview of study groups, upcoming sessions, tasks, and progress.
- **Study Groups:** Allows users to search for study groups and use the available options to join or create groups.
- **Study Scheduler:** Allows users to enter study-session details, including the title, date, time, and duration. The prototype includes basic checks for past dates and overlapping sessions.
- **Task Tracker:** Allows users to add tasks, manage due dates, mark tasks as complete, and view progress.
- **My Profile:** Allows users to view and update basic profile details.

## 3. How to Run the Website

1. Save the website file as `studysync.html`.
2. Open the file in a modern web browser, such as Google Chrome, Microsoft Edge, Firefox, or Safari.
3. Use the website navigation to explore the different sections.

The prototype runs locally in the browser and does not require a separate installation or server.

## 4. Technologies Used

- **HTML:** Provides the structure of the website.
- **CSS:** Controls the styling, layout, and responsive design.
- **JavaScript:** Provides interactive features and prototype functionality.
- **Browser localStorage:** Saves supported data locally in the browser.

## 5. Visual Design Rationale

StudySync uses a clean, organised, and consistent visual style to help students find features quickly and understand the interface. Clear labels, familiar controls, feedback messages, and progress indicators are intended to support visibility, learnability, efficiency, and motivation.

## 6. Prototype Limitations

- Data saved using `localStorage` remains in the browser on the device where it was entered.
- The prototype does not include a server, central database, or real-time data sharing between users or devices.
- Production-grade account authentication and password security are not implemented.
- Automated notifications and external calendar integration are not included.
- Accessibility has not been formally audited. Responsive design and keyboard-focus styling alone do not establish full WCAG compliance.

## 7. Suggested Testing

Before demonstrating or submitting the prototype:

1. Open the website and check that the navigation works.
2. Test the available study group actions.
3. Add a study session and test the date and time validation.
4. Add a task, mark it as complete, and check the progress display.
5. Update profile details and refresh the page to check which information persists.
6. Check the layout on desktop and mobile screen sizes.


## 8. Project Purpose

StudySync is a Human-Computer Interaction (HCI) learning prototype that demonstrates how interface design principles can be applied to a student study-planning website. It is intended to support academic organisation and collaboration rather than replace a production learning-management system.
